# General info
This bot helps to notify you about trainings for the current day. You can also set a time of notification by yourself.
**Tech stack**

-telebot -sqlalchemy

**First launch**

navigate to the repository's root directory
install all the dependencies: `pip3 install -r ./requirements.txt`
create a database: `pyton3 ./database_create.py`
launch the bot: `python3 ./assistant_bot.py`
